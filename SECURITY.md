# Security Policy

## Scope

This policy covers security vulnerabilities in the A11y Relay source code and project infrastructure.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability.

Until a dedicated security contact is published, report security concerns privately to the project maintainers. Include:

- A clear description of the vulnerability
- Steps to reproduce it
- The affected component or version
- Potential impact
- A suggested mitigation, if available

Do not include real user data, credentials, personal information, or private accessibility evidence in a report.

## Response expectations

Maintainers will acknowledge a report when possible, investigate the issue, and coordinate disclosure with the reporter. We will prioritize risks involving unauthorized access, evidence exposure, authentication, and privacy.

## Secure development principles

- Keep evidence private by default.
- Minimize collected personal data.
- Never commit secrets or real user data.
- Validate uploaded files and external URLs.
- Use dependency updates and automated checks.
- Document security-sensitive behavior.
